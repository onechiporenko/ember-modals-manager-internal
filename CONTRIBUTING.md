# How To Contribute

## Installation

- `git clone https://github.com/onechiporenko/ember-bootstrap-modals-manager.git`
- `cd ember-modals-manager-internal`
- `pnpm install`

## Linting

- `pnpm run lint`
- `pnpm run lint:fix`

## Running tests

- `pnpm run test` – Runs the test suite on the current Ember version
- `pnpm run test:ember -- --server` – Runs the test suite in "watch mode"
- `pnpm run test:ember-compatibility` – Runs the test suite against multiple Ember versions

## Running the dummy application

- `pnpm run start`
- Visit the dummy application at [http://localhost:4200](http://localhost:4200).

For more information on using ember-cli, visit [https://cli.emberjs.com/release/](https://cli.emberjs.com/release/).
